# 🔍 Compare Values — True or False?

Python can compare values using **comparison operators**. These comparisons always return a **Boolean** result: `True` or `False`.

Use them to:

* Make decisions
* Run conditions in `if` statements
* Check for equality or difference

---

## 💡 Comparison Operators

| Operator | Meaning                  | Example  | Result  |
| -------- | ------------------------ | -------- | ------- |
| `==`     | Equal to                 | `5 == 5` | `True`  |
| `!=`     | Not equal to             | `3 != 4` | `True`  |
| `>`      | Greater than             | `7 > 2`  | `True`  |
| `<`      | Less than                | `2 < 1`  | `False` |
| `>=`     | Greater than or equal to | `4 >= 4` | `True`  |
| `<=`     | Less than or equal to    | `3 <= 2` | `False` |

---

## 💻 Example with Explanation

```python
print(10 == 10)   # True
print(5 != 3)     # True
print(8 > 6)      # True
print(4 < 4)      # False
print(6 >= 5)     # True
print(3 <= 3)     # True
```

### 🔈 Output

```
True
True
True
False
True
True
```

---

### 📌 Key Notes

* `==` checks if values are equal
* `!=` checks if values are different
* These comparisons work on numbers, strings, and even variables
* You can use them inside `if` statements to control logic

---

## 🧪 Try It Yourself

```python
x = 7
y = 10

print("Is x equal to y?", x == y)
print("Is x not equal to y?", x != y)
print("Is x less than y?", x < y)
```

### 🔈 Expected Output

```
Is x equal to y? False
Is x not equal to y? True
Is x less than y? True
```
